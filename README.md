TP associé au cours HPC-BIG-DATA 2627

Les scripts s'utilisent à l'aide du gestionnaire de projet `uv`
Ce gestionnaire nécessite d'être installé sur votre machine: https://docs.astral.sh/uv/getting-started/installation/


```bash
# Installation des packages dans le répartoire où se trouve votre `pyproject.toml` 
uv sync 
```
Ensuite dans vscode, il faut choisir le moteur python associé.
